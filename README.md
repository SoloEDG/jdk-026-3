安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

## 假设推演空间

当两种走法都像正确时，可以不动主盘，从当前盘面开一条支线：

- **分支与嵌套**：主盘或任一支线都能再开分支。每条支线记录的是相对「共同起点快照」的差异（`changes`），快照按盘面内容寻址，刷新后父子关系与路线都能还原。
- **互不影响**：支线里的填涂、检查、计时和提示都落在该路线上；支线走通不会写入完成记录，也不会解锁作品。提示额度由主盘统一计数，支线与主盘共用，丢弃支线不返还已用额度。
- **回到主盘**：主盘进度原样保留，可继续原来的推理。
- **逐格合并**：合并时以支线相对起点的变化为准，和主盘现状逐格比较，区分「可直接合并 / 已经一致 / 冲突」。冲突默认保留主盘，也可逐格选择采用支线；确认后作为一次提交写入，主盘一次撤销即可整体回退（回退同时重新打开该支线并撤销它带来的完成记录）。
- **路线对比**：同一起点的支线可以并排比较，不同起点的路线分组显示。
- **安全边界**：共同起点快照丢失或指纹不符时，该支线停止切换与合并，并给出提示，绝不会静默覆盖主盘。

保存格式仍是 `gejian.document.v1`，新增的 `hypothesis` 字段缺失时会按旧存档兼容载入。
